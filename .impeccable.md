## Design Context

### Users
Quantitative researchers and traders who repeatedly inspect strategy backtests, compare risk and return, review attribution, and verify position history in a work-focused desktop interface.

### Brand Personality
Quiet, precise, restrained, and operational. The interface should communicate analytical confidence without decorative dashboard styling.

### Aesthetic Direction
A light, data-dense quantitative workstation with compact controls, transparent chart plotting areas, restrained borders, consistent chart geometry, and typography optimized for scanning numeric information.

### Design Principles
- Make comparisons fast: consistent legends, axes, number formats, tooltips, and interaction behavior across every chart.
- Maximize useful plotting area while preserving enough margin for readable labels and controls.
- Use color only to encode data meaning; keep surfaces, grids, and decoration visually quiet.
- Prefer shared chart tokens and primitives over chart-specific CSS overrides.
- Preserve keyboard access, responsive behavior, and stable layout at desktop, narrow desktop, and mobile widths.
